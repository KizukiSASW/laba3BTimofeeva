# Практическое задание 3Б — «Справочник пользователей»

Объединение модуля 2 (DOM и события) и модуля 3 (fetch, async/await, JSON, HTTP).
Приложение на чистом JavaScript без фреймворков.

## Состав проекта

- `index.html` — разметка интерфейса (кнопка загрузки, поле поиска, список пользователей, область публикаций, область сообщений);
- `style.css` — оформление (карточки, кнопки, цветовые состояния сообщений);
- `app.js` — логика: GET пользователей, поиск по имени, GET публикаций по `userId`, обработка ошибок;
- `README.md` — этот файл.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере (двойной клик) — локальный сервер не обязателен.
   При желании: `python -m http.server 8000` и открыть `http://localhost:8000`.
3. Для запросов нужен доступ в интернет
   (API: `https://jsonplaceholder.typicode.com`).

## Результаты проверки

- **«Загрузить пользователей»** → появляются 10 пользователей с именем, email и городом.
  Во время запроса показывается «Загрузка пользователей…», кнопка отключена, затем снова активна.
- **Поиск по имени** (без нового HTTP-запроса) → фильтрует уже загруженный список без учёта регистра.
  - Ввод `Leanne` → остаётся подходящая запись.
  - Ввод неизвестного имени → сообщение «Пользователи не найдены».
- **«Показать публикации»** → запрос `…/posts?userId=ID`, выводятся заголовки и тексты первых трёх публикаций выбранного пользователя в отдельной области.
- **Проверка ошибки HTTP (404)**: при временной замене `/users` на `/userz` появляется сообщение об ошибке,
  кнопка снова активна, повторный запрос после возврата правильного адреса работает.
- Сетевые сбои и таймауты (8 с через `AbortSignal.timeout`) обрабатываются через `try/catch/finally`.
- Текст выводится через `textContent` (защита от XSS), страница не перезагружается.

## Технические детали

- Чистый HTML/CSS/JS, без фреймворков.
- События — `addEventListener`; элементы создаются через `createElement` и `DocumentFragment`.
- `response.ok` проверяется перед разбором JSON.
- Кнопки блокируются на время запросов и разблокируются в `finally` — повторная попытка всегда возможна.
